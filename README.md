## 🌐 What is TORCH?

**TORCH (The Open Routing & Community Hub)** is an independent, browser-centered digital ecosystem built around its own custom domain namespace: `.torch`.

TORCH Browser is the official gateway to this ecosystem. Unlike conventional web browsers, it is designed specifically to resolve and access websites within the TORCH network.

Domains such as `.com`, `.org`, `.in`, `.io`, and `.xyz` are not supported as browsing destinations.

Instead, TORCH introduces its own domain environment, services, and browsing experience.

**TORCH is not just another web browser. It is the gateway to an independently designed digital world.**

## ✨ Key Features

- **Native `.torch` Navigation** — Access websites using the TORCH domain namespace.
- **Integrated DNS Registry** — Resolve registered `.torch` domains through the TORCH DNS registry.
- **Multi-Tab Browsing** — Open and manage multiple TORCH websites.
- **Bookmark Manager** — Save and revisit your favorite `.torch` destinations.
- **Browsing History** — View and manage previously visited destinations.
- **Quick Navigation** — Access important TORCH services directly from the browser.
- **TORCH Shield** — Switch between Standard and Strict browsing modes with different iframe sandbox restrictions.
- **Modern Interface** — A responsive browsing experience with light and dark themes.

## 🧭 How TORCH Browsing Works

TORCH Browser uses its own domain-resolution mechanism.

1. A user enters a `.torch` address.
2. The browser checks the address against its TORCH DNS records.
3. If a matching record exists, the browser resolves its associated destination.
4. The destination is displayed inside the browser's browsing interface.

Unregistered domains display an NXDOMAIN page.

## 🛡️ TORCH Shield

TORCH Browser includes two browsing modes:

- **Standard Mode:** Uses the standard iframe sandbox permissions configured by the browser.
- **Strict Mode:** Applies more restrictive iframe sandbox permissions, including removing popup and modal permissions.

These modes provide different content restrictions. They should not be considered a guarantee of anonymity, complete tracker blocking, or complete security.
