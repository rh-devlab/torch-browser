# 🔥 TORCH Browser — Sovereign `.torch` Web Engine

**TORCH Browser** is a fast, mobile-first, zero-build single-file browser engineered specifically to navigate the independent **`.torch` Sovereign Web Ecosystem**. It resolves `.torch` domains natively outside traditional ICANN registries and enforces strict sandboxed security.

## ✨ Core Features & Architecture

1. **Native `.torch` Protocol Resolution:**
   - Connects directly to the decentralized TorchDNS lookup table (`all-domains.json`) to resolve `.torch` websites in real time.
   - Blocks external commercial TLDs (`.com`, `.org`) to keep the network distraction-free and pure.

2. **Zero-Knowledge TORCH ID (8-Word Cryptographic Identity):**
   - Built-in BIP-39 8-word seed phrase generator and authentication terminal at browser startup.
   - Your raw seed phrase never leaves your device; a client-side SHA-256 `idHash` provides seamless **Single Sign-On (SSO)** across all `.torch` portals (`git.torch`, `host.torch`, `torch.torch`) without passwords or emails.

3. **TORCH Shield (Sandboxed Execution):**
   - **Standard Mode:** Allows safe interactive web apps, forms, and scripts inside isolated iframes.
   - **Strict Mode:** Enforces maximum isolation, blocking popups and restricting script execution for untrusted nodes.

4. **Full Mobile-First Browser Chrome:**
   - Multi-tab management with live visual tab switcher grid.
   - Persistent bookmarks bar, browsing history drawer, and dark/light theme support.
   - Engineered as a pure, zero-dependency single-file HTML5/CSS3/ES2025+ application.
